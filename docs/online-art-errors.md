# غلاف الأغاني الإنترنتية ورسالة فشل التشغيل

- Track: حقل اختياري artworkUrl.
- AudiusClient: يقرأ رابط الغلاف (480 ثم 150).
- AlbumArt: يحمّل الغلاف من الرابط ويخزّنه مؤقتاً بمفتاح الرابط.
- PlayerController: playbackErrors يصدر عند فشل مقطع (يُتخطى كما قبل).
- GlowApp: رسالة «تعذّر تشغيل الأغنية، تم تخطيها».

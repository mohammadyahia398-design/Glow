# المشغّل المصغّر — إعادة تصميم

- إزالة كل ألوان الغلاف المتسرّبة (تدرّجات، وهج ملوّن، حافة متدرجة، ظل ملوّن).
- السطح: skin.panel (محايد) + زجاج سائل (vibrancy + blur + lens) عبر liquidBackdrop المشترك مع الشريط السفلي؛ بديل صلب للأجهزة بلا انكسار.
- حافة واحدة موحّدة: skin.glassBorder بشفافية 0.30، وزوايا 36dp.
- زر التشغيل بنفس تدرّج وحافة GlowFilledButton؛ السابق/التالي بلون النص فقط.
- المنزلق: منطقة 36dp تتّسع للمقبض المضغوط (24dp × 1.5) فلا يخرج عن الكبسولة؛ هوامش أفقية 36dp.
- الارتفاع 76dp → 92dp (ArtMiniPlayerHeight).
- GlowApp: تمرير backdrop = liquidBackdrop عند دعم الانكسار.

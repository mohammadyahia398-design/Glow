# شاشة الإعدادات — إعادة تصميم

- شريط علوي: زر رجوع دائري (skin.chip) وعنوان في الوسط، بدل العنوان الكبير.
- بطاقات مجمّعة موحّدة (زوايا 22dp، حافة واحدة 1dp، زجاج سائل مع بديل صلب)، بلا عناوين أقسام، والمسافة بينها 12dp.
- كل الصفوف بارتفاع واحد (58dp min): أيقونة خطية محايدة، عنوان، قيمة، سهم أو مفتاح؛ فواصل دقيقة تبدأ بعد الأيقونة.
- المظهر: مفتاح مقسّم (النظام / فاتح / داكن) بدل بطاقات المعاينة الكبيرة.
- لون التمييز للحالة الفعّالة فقط: المفتاح، الخيار المحدد، الزر الرئيسي.
- «إعادة فحص المكتبة» صارت الزر الرئيسي أسفل الشاشة، والإصدار سطر صغير تحته (حُذف قسم «حول»).
- «عزل الصوت» صف بسطر واحد. وحُذف وهج الخلفية الثاني.

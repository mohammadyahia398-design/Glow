# ويدجت الشاشة الرئيسية — الدفعة 5 من 5

- يظهر في قائمة الويدجت باسم التطبيق، بحجم 4×2 تقريباً ويقبل تغيير الحجم.
- المحتوى: غلاف مدوّر، العنوان، الفنان، أزرار السابق / تشغيل-إيقاف / التالي بنفس هوية التطبيق (تدرّج نيلي، زر Magenta→Violet).
- الضغط على الجسم يفتح التطبيق. الأزرار تتصل بخدمة التشغيل نفسها التي يستعملها الإشعار.
- حالة السكون (لا أغنية أو أُغلقت الخدمة): «Glow — اضغط لفتح التطبيق» بلا أزرار، حتى لا تُشغَّل الخدمة بلا طابور.
- يتحدّث من GlowMediaSessionService عند تغيّر الأغنية أو التشغيل/الإيقاف ووصول الغلاف، وعند إغلاق الخدمة.
- بلا مكتبات جديدة (RemoteViews كلاسيكي). ملفات جديدة: widget/GlowWidget.kt، layout/glow_widget.xml، xml/glow_widget_info.xml، drawable/glow_widget_bg.xml وglow_widget_play_bg.xml؛ معدّل: AndroidManifest.xml وGlowMediaSessionService.kt.

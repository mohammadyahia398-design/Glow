# حالة تحميل المكتبة وقائمة الترتيب (الدفعة 4)

- أثناء فحص المكتبة (loaded = false مع وجود صلاحية) تظهر GlowLoading بنص «جارٍ فحص المكتبة…» بدل شاشة فارغة. لا تظهر في تبويب Spotify.
- في تبويبي الأغاني والمفضلة يظهر زر زجاجي «الترتيب: ...» تحت الترويسة، يفتح GlowChoiceDialog بأربعة خيارات: العنوان، الفنان، الأحدث، المدة (الأطول أولاً).
- الترتيب يحفظ عبر rememberSaveable (يبقى مع تدوير الشاشة، لا مع إغلاق التطبيق). والتشغيل يتبع الترتيب المعروض.
- الألبومات والفنانون والأنواع تبقى مرتبة بالاسم.
- ملف معدّل واحد: ui/library/LibraryScreen.kt.

# ألوان Glow الجديدة (الدفعة 2 — تكملة الدفعة 1)
- أزرار حوارات التأكيد الرئيسية بتدرّج الهوية (ماجنتا ← بنفسجي) بدل الصلب الفاتح/الداكن.
- زر تشغيل المشغّل المصغّر بنفس تدرّج الهوية (accentBrush).
- الشاشة الافتتاحية وأيقونة البلاطة وخلفية الأيقونة: تدرّجات الهوية بدل الأخضر والأزرق القديمين؛ خلفية الأيقونة 000002.
- وهج الإعدادات الخلفي أخفّ (0.08).
- حالات التحميل: شرارات رباعية رفيعة خفيفة جداً تلمع لحظة وتخبو (الحلقة، الكرات، شريط التقدّم)، والكرات بماجنتا + بنفسجي.

# رسائل التأكيد الزجاجية (Snackbar)

## الجديد
- `ui/common/GlowSnackbar.kt`: `GlowSnackbarState` (رسالة واحدة في كل مرة) و`GlowSnackbarHost` و`LocalGlowSnackbar`.
- الشكل: كبسولة بنفس زجاج المشغّل المصغّر (أندرويد 13+ تنكسر الخلفية خلفها)، وقبل ذلك كبسولة مسطحة بإطار.
- تختفي تلقائياً: 3 ثوانٍ، و5 ثوانٍ إن كان فيها «تراجع». الرسالة الجديدة تحلّ محل القديمة.

## أين تظهر
- المفضلة: إضافة/إزالة مع «تراجع».
- الطابور: «سيُشغَّل بعد المقطع الحالي» و«أُضيف إلى نهاية الطابور» مع «تراجع»؛ وإن كان المقطع موجوداً أصلاً تظهر رسالة بلا تراجع.
- القوائم: الإضافة إلى قائمة (مع تراجع، أو «موجود بالفعل»)، وإنشاء قائمة جديدة (التراجع يحذفها).

## ملاحظات
- المضيف في GlowApp خارج مصدر الخلفية، فوق الشريط السفلي والمشغّل المصغّر، وتحت المشغّل الكامل. يرتفع ويهبط بحركة ناعمة مع ظهور الشريط والمشغّل.
- الملفات المعدّلة: GlowApp.kt وLibraryScreen.kt.

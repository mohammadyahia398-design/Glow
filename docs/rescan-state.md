# patch-10-rescan

عند الضغط على «إعادة الفحص» من الإعدادات:
- تصبح loaded = false أثناء الفحص، فتظهر شاشة «جارٍ فحص المكتبة…» في المكتبة.
- عند الانتهاء تظهر رسالة: «تم تحديث المكتبة، عدد الأغاني: N».
- أول تحميل عند فتح التطبيق لا يتغير (rescan = 0) ولا تظهر الرسالة.

الملف المعدّل: app/src/main/java/com/glow/app/ui/navigation/GlowApp.kt

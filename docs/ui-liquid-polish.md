# صقل الزجاج السائل والقوائم

- عزل الصوت: خلفية بوهجين تنكسر خلف البطاقات (LiquidGlassCard) والأزرار والحقل، مثل الإعدادات. زر «اختبار الاتصال» بسطر واحد وعرض يناسب نصه.
- الإعدادات: وهج أقوى خلف البطاقات ليظهر الانكسار.
- النوافذ: زر الإلغاء/الإغلاق بنفس هامش الصفوف (24dp)، وفراغ أصغر بين الراديو والنص، ومعامل `icon` اختياري في `GlowDialogRow`.
- نافذة أغنية البحث: أيقونة القلب والتحميل، وتباعد أسطر أضيق للرسالة.
- حقل البحث في الأغاني وحقل اسم القائمة: زجاج سائل.

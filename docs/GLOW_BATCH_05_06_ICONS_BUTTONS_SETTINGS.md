# Glow — الدفعتان 5 و6 (مدمجتان): الأيقونات والأزرار والإعدادات

## الأيقونات (5)
- `ui/icons/CoreGlyphs.kt`: 18 أيقونة على IconEngine (شبكة 24، خط 1.8، أطراف مدوّرة) تشمل Up وClose الجديدتين.
- `ui/common/GlowIcons.kt`: كل IconKind يُرسم عبر المحرّك؛ Play/Pause/Next/Prev ممتلئة.

## الأزرار (6)
- جديد `ui/common/GlowButtons.kt`: GlowFilledButton / GlowOutlinedButton / GlowTextButton / GlowRoundButton (كبسولات بضغطة نابضة).
- استُبدلت أزرار Material الافتراضية في: فصل الصوت (6 أزرار)، قائمة التشغيل (مسح القادم + أسهم ↑ ↓ × صارت أيقونات)، المعادل (إعادة ضبط)، شاشة التشغيل (زر قائمة التشغيل).

## الإعدادات (6)
- `ui/settings/SettingsScreen.kt`: عناوين أقسام صغيرة بلون ثانوي، بطاقات بتدرّج وحافة زجاجية ولمعة علوية،
  أيقونات داخل مربّعات بلون التمييز، فواصل تبدأ بعد الأيقونة. السلوك والخيارات لم تتغير.

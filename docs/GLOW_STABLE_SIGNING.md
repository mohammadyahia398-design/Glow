# توقيع ثابت للتحديث فوق النسخة المثبّتة

- السبب: build.yml يبني assembleDebug على GitHub، وكل تشغيل يولّد مفتاح debug جديداً، فيعدّه أندرويد تطبيقاً مختلفاً ويرفض التحديث («متعارض مع الحزمة الحالية»).
- الحل: app/glow-debug-signing.p12 ثابت (PKCS12، امتداده ليس .jks/.keystore كي لا يتجاهله .gitignore) + signingConfig لنوع debug في app/build.gradle.kts.
- مرة واحدة فقط: النسخة المثبّتة حالياً موقّعة بمفتاح قديم، فيلزم حذفها قبل تثبيت أول بناء بالمفتاح الجديد. بعدها تُحدَّث كل النسخ فوق بعضها دون حذف.
- ملاحظة: المفتاح للتجربة الشخصية فقط، وكلمته معلنة في build.gradle.kts؛ لا يصلح لنشر التطبيق على Play.
